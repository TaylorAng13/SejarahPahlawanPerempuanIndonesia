# Dari Dapur ke Ruang Publik

Website artikel wawancara tentang pandangan masyarakat terhadap peran wanita sebelum, saat, dan setelah masa perjuangan, termasuk kisah Siti Manggopoh.

Halaman tunggal (HTML + CSS + JS), tanpa build step.

## Cara melihat
Buka `index.html` di browser, atau aktifkan GitHub Pages (Settings > Pages > Deploy from a branch > `main` / root).
